# Portfolio Website

A modern, simple yet attractive portfolio website featuring a samurai-themed hero section.

## 🚀 Features

- **Stunning Hero Section**: Eye-catching samurai image with smooth parallax effect
- **Responsive Design**: Looks great on all devices (desktop, tablet, mobile)
- **Smooth Animations**: Fade-in effects and smooth scrolling
- **Modern UI/UX**: Clean, minimalist design with elegant typography
- **Interactive Elements**: Hover effects, animated counters, and dynamic navigation
- **Contact Form**: Easy way for visitors to get in touch

## 📁 Project Structure

```
portfolio/
├── index.html       # Main HTML file
├── styles.css       # All styling
├── script.js        # JavaScript functionality
├── samurai.jpg      # Hero background image
└── README.md        # This file
```

## 🎨 Setup Instructions

1. **Add Your Image**: 
   - Save your samurai image as `samurai.jpg` in the project root directory
   - The image should be high resolution (at least 1920x1080px) for best results

2. **Customize Content**:
   - Open `index.html` and update:
     - Your name and title
     - About section text
     - Project details
     - Skills and technologies
     - Social media links in the footer

3. **Open in Browser**:
   - Simply double-click `index.html` or open it in your browser
   - For local development, you can use a local server

## 🛠️ Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #ffffff;
    --secondary-color: #000000;
    --accent-color: #f4f4f4;
}
```

### Typography
The portfolio uses the 'Inter' font from Google Fonts. You can change it by updating the link in `index.html`.

### Sections
You can easily add or remove sections by copying the section structure in `index.html`.
